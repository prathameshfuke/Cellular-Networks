## Project Overview
This repository contains the MATLAB implementation for the Cellular Networks laboratory experiments. Each script is designed to simulate specific wireless communication concepts, including propagation models, fading effects, channel estimation, and system capacity.

## Experiment List and MATLAB Scripts

### Experiment 1: Hata Propagation Model
File: matlab/Exp1_Hata_Model.m
Description: Implements the Hata model for Urban, Suburban, and Rural environments to calculate path loss and received signal levels.

### Experiment 2: BPSK BER in AWGN
File: matlab/Exp2_AWGN_BPSK.m
Description: Simulates the Bit Error Rate (BER) performance of BPSK modulation over a wireline AWGN channel for SNR 0 to 50 dB.

### Experiment 3: BPSK BER in Rayleigh Fading
File: matlab/Exp3_Rayleigh_BPSK.m
Description: Simulates the BER performance over a Rayleigh fading wireless channel and compares it with theoretical values.

### Experiment 4: Channel Estimation
File: matlab/Exp4_Channel_Estimation.m
Description: Estimates the fading channel coefficient using pilot symbols and calculates the Mean Square Error (MSE).

### Experiment 5: RMS Delay Spread
File: matlab/Exp5_RMS_Delay_Spread.m
Description: Computes Mean Excess Delay and RMS Delay Spread for a given Power Delay Profile (PDP).

### Experiment 6: Link Budget Analysis
File: matlab/Exp6_Link_Budget.m
Description: Performs a systematic listing of power gains and losses to calculate the required transmit power and achieved SNR.

### Experiment 7: MIMO Diversity Performance
File: matlab/Exp7_MIMO_Rayleigh.m
Description: Simulates BER performance for SISO vs. SIMO (1x2) with Maximal Ratio Combining (MRC) in Rayleigh fading.

### Experiment 8: Cellular System Capacity
File: matlab/Exp8_Cellular_Capacity.m
Description: Calculates the total number of users supported in a city based on Erlang B blocking probability and cell radius.

### Experiment 9: LAN Implementation
Note: This experiment is performed using Cisco Packet Tracer and does not require a MATLAB script.

### Experiment 10: Doppler Shift Calculation
File: matlab/Exp10_Doppler_Shift.m
Description: Computes the Doppler shift for different carrier frequencies and mobile speeds.

### Experiment 11: Handoff Mechanism
Note: This experiment is performed using VLAB and does not require a MATLAB script.
